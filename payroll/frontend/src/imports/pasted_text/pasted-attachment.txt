คุณเป็น Senior UX/UI Designer, Product Designer และ Frontend System Designer ที่มีประสบการณ์ออกแบบระบบ Payroll, HRIS, Enterprise Web Application และระบบสำหรับหน่วยงานราชการไทย

ให้ออกแบบ Web Application สำหรับระบบจัดทำเงินเดือนและส่งสลิปเงินเดือน โดยใช้ไฟล์โปรเจกต์ Payroll ที่แนบมาเป็น Demo และข้อมูลอ้างอิงเท่านั้น

โปรเจกต์เดิมเป็นระบบตัวอย่างที่ผู้พัฒนาได้สร้างไว้ให้ทดลองใช้งานและสามารถแก้ไขเพิ่มเติมได้ ดังนั้นไม่จำเป็นต้องรักษาหน้าตา เมนู หรือขั้นตอนทั้งหมดจากโปรเจกต์เดิม

ให้ยึด User Requirement ที่ระบุใน Prompt นี้เป็นหลัก

สามารถนำหน้าจอ ฟีเจอร์ Component หรือ Workflow จากโปรเจกต์เดิมมาใช้ได้ เฉพาะส่วนที่สอดคล้องกับ Requirement ใหม่ เช่น
